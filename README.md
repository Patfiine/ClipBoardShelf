# ClipboardShelf

Простое macOS-приложение в строке меню, которое сохраняет историю скопированных текстов и снимков экрана, а также позволяет быстро выбирать и вставлять нужный элемент.

## Что умеет

- Следит за буфером обмена macOS.
- Сохраняет последние 50 текстовых элементов.
- Сохраняет последние 20 снимков экрана из буфера обмена.
- Разделяет тексты и снимки по отдельным вкладкам.
- Позволяет заново скопировать элемент кнопкой `Выбрать`.
- Позволяет сразу вставить выбранный элемент маленькой кнопкой слева от `Выбрать`.
- Поддерживает горячую клавишу открытия приложения.
- Поддерживает навигацию по истории через клавиатуру.
- Сохраняет историю между запусками.

## Как открыть проект

1. Установи полный Xcode, а не только Command Line Tools.
2. Открой `ClipboardShelf.xcodeproj` в Xcode.
3. Выбери target `ClipboardShelf`.
4. Нажми `Run`, и Xcode соберет полноценный `ClipboardShelf.app`.
5. После первой сборки готовое приложение можно найти в `Products` внутри Xcode.

## Как запускать без Xcode

1. Выполни скрипт `Scripts/install_app.sh`.
2. Он соберет приложение и скопирует его в `~/Applications/ClipboardShelf.app`.
3. После этого открывай `ClipboardShelf.app` как обычное приложение macOS без Xcode.

## Горячие клавиши

- `Command + Shift + Space` — открыть или скрыть приложение.
- `Command + Up / Down` — выбрать предыдущий или следующий элемент.
- `Command + Left / Right` — переключить вкладку.
- `Command + Return` — моментально вставить выбранный элемент.
- `Command + Shift + V` — альтернативная горячая клавиша моментальной вставки.

## Как работает

Приложение опрашивает `NSPasteboard.general.changeCount`. Когда значение меняется, оно читает текст или изображение из буфера обмена и добавляет элемент в соответствующую вкладку.

Поддерживаются два сценария со скриншотами:

- скриншот попадает в буфер обмена;
- скриншот сохраняется на рабочий стол стандартной командой `Command + Shift + 4`.

Для функции мгновенной вставки приложению нужен доступ в `System Settings -> Privacy & Security -> Accessibility`.

## Где искать .app

Если приложение уже собрано в Xcode, открой левую панель Project Navigator, затем секцию `Products`, найди `ClipboardShelf.app`, нажми по нему правой кнопкой и выбери `Show in Finder`.
